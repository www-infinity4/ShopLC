# ShopLC Live Companion

A GitHub Pages shopping-channel experiment built around Shop LC's official YouTube live stream.

## What this build tests

- muted autoplay that joins the official Shop LC stream live on mobile
- one-tap sound enablement for Android autoplay rules
- direct shopping paths for the current on-air item, hot deals, special offers, offer inventory and $1 auctions
- rotating contextual commercial concepts around the live program
- local impression, click and CTR counters for the commercial experiment
- channel share support and the existing 10-shares-per-StarCoin local progress behavior
- social preview metadata using the official live-stream thumbnail

The companion page does not copy volatile product pricing. Shop LC remains the source of truth for price, inventory, checkout, shipping, returns and fulfillment.
